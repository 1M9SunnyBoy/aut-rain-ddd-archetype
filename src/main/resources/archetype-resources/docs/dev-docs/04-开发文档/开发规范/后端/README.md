${hash} 后端开发规范

版本：v1.0；更新：2026-11-02。适用于本脚手架生成的 Java 工程。

本文定义通用技术规则。具体业务模型、状态机、日期关系及登录授权由项目设计确定，不要求所有接口和页面在数据库登记。可选架构的专属约束应记录到架构文档，不作为所有生成项目的默认要求。

${hash}${hash} 1. 技术基线与范围

Java 21、Maven 3.9+，依赖版本由父 POM 和导入的 BOM 统一管理；具体版本以工程配置为准，插件与运行库升级需一并验证。后端禁止引入和使用 Lombok。

当前模板提供六模块 DDD 骨架、基础响应/异常/校验类型、配置与 Flyway 基线。缓存、RPC、消息、任务和对象存储的目录或 Compose 环境不代表已实现业务集成；按需引入依赖并在 app/config 装配。

${hash}${hash} 2. 模块和模型边界

| 模块 | 职责 | 当前内部依赖 |
| --- | --- | --- |
| types | 通用响应、异常、校验与跨模块常量 | 无 |
| api | 对外接口契约与 DTO | types |
| domain | 聚合、实体、值对象、领域规则、仓储和外部能力端口 | types |
| infrastructure | 数据持久化、外部调用和缓存适配 | domain |
| trigger | HTTP/RPC/消息/任务入口，输入输出转换 | api、domain、types |
| app | Spring 装配、配置、迁移、启动和测试 | trigger、infrastructure |

领域层不依赖基础设施或 HTTP 框架；trigger 不直接访问 Mapper。DTO、PO、领域对象按职责分离，避免持久化字段意外暴露到 API。

目录采用 DDD 分层：domain/<领域>/model/{aggregate,entity,valobj}、service、repository、adapter；infrastructure/persistent/{dao,po,repository}、gateway/{api,dto,adapter}、redis；trigger/{http,rpc,listener,job}。示例 xxx/yyy 改为实际领域名，package-info.java 保留包职责，不增加无行为的占位类。

${hash}${hash} 3. Java 编码与配置

使用显式构造方法注入。按对象职责实现构造方法、访问器、equals/hashCode/toString，可采用适用的不可变 record；不要求所有对象都生成 setter。日志显式声明 SLF4J Logger，不使用 @Slf4j。

异常保留 cause，禁止吞异常、空 catch 或用返回 null 伪装成功。密码、凭据、个人信息不得进入 toString、日志和外部错误信息。公共方法表达明确语义，不使用无边界的万能工具类。

配置按开发、测试和生产环境分离，生产敏感值通过外部配置提供，不提交真实 .env。配置缺失时提供可定位的错误。新增中间件接入只在功能需要时启用，不能让所有生成项目强制依赖全部中间件。

${hash}${hash} 4. 接口契约与响应码

普通 JSON 接口使用 ApiResponse 的 code/message/data，成功码为字符串 "00000"。新增接口在契约中明确字段命名、必填、null、默认值、分页和排序规则。新接口字段默认沿用 camelCase，与当前响应结构一致；需 snake_case 时在项目级统一约定和映射，禁止同一契约随意混用。

业务 ID 对外使用字符串，避免 JavaScript 精度丢失；高精度金额使用 BigDecimal，在接口中明确十进制字符串与精度。时间点使用带时区的 ISO 8601，业务日期使用 YYYY-MM-DD。分页必须限制单页数量，排序字段通过白名单映射，不直接拼接外部输入。

业务响应码采用 Constants.ResponseCode 内嵌枚举形式，定义于 types/common/Constants.java，分类注释参考《阿里巴巴 Java 开发手册》：00000 成功，Axxxx 用户端错误，Bxxxx 当前系统错误，Cxxxx 第三方服务错误。保持字符串格式、语义稳定，不重复分配；程序判断 code，文案可以调整。

| 枚举 | 业务码 | 默认提示 | 当前 HTTP 映射 |
| --- | --- | --- | --- |
| SUCCESS | 00000 | 成功 | Controller 决定，ping 为 200 |
| ILLEGAL_PARAMETER | A0400 | 用户请求参数错误 | 400 |
| SYSTEM_ERROR | B0001 | 系统执行出错 | 500 |
| THIRD_PARTY_ERROR | C0001 | 调用第三方服务出错 | 503 |

HTTP 映射是本项目约定，不是阿里业务码规范的要求。用 new BusinessException(Constants.ResponseCode.ILLEGAL_PARAMETER) 抛出预期错误，可附加 cause。字符串构造方法保留扩展能力，当前未特别映射的业务码默认返回 400；新增业务码必须显式评审 HTTP 映射，不能仅按字母前缀推断。

未知异常当前返回 B0001，隐藏底层信息。ValidationUtils 目前仍使用 VALIDATION_ERROR，后续统一前不能声称所有失败都已经采用五位编码。框架参数校验异常也需按新增接口需求补充映射，不能把通用异常处理器视为完整校验支持。

创建资源可用 201，无响应体可用 204；未认证、无权限、资源不存在、状态冲突、限流分别使用适当的 HTTP 状态。文件下载和流式接口不强行套 JSON。当前没有 traceId 响应字段；引入追踪时统一请求、响应和日志关联，避免重复记录相同异常堆栈。

${hash}${hash} 5. 输入、授权与逻辑外键

Controller 校验输入格式、长度、范围和类型；领域层校验状态和业务不变量。列表、详情、修改和删除均需校验数据归属，不能只验证 ID 存在，也不能把路径中的错误父级自动纠正。

项目若启用认证授权，后端必须检查实际权限，前端隐藏按钮不能替代检查。具体人员、角色和数据范围模型由业务设计确定，模板不预设模拟身份。

禁止物理外键，关联写入在事务中校验父对象存在、状态及归属。父对象更新或删除也必须采用一致的并发控制协议，保证校验后到提交前不会产生孤儿；一次普通 SELECT 后直接 INSERT 不构成完整兜底。保留唯一约束和必要索引，完整性诊断不能替代事务约束。

${hash}${hash} 6. 事务、并发和外部调用

事务覆盖一个明确的业务一致性边界，事务入口放在 Spring 管理且可经代理调用的服务方法；验证回滚行为，不依赖同类自调用触发事务。事务时长保持可控，不在持锁期间执行不必要的远程调用。

每个业务设计固定加锁顺序，同类记录按稳定 ID 顺序处理，不沿用其他业务的实体锁顺序。采用 version 乐观锁时，条件更新必须包含旧版本并检查影响行数；冲突明确返回，禁止静默覆盖。

需要幂等的创建、支付、消息等操作，定义幂等键作用域、唯一约束、保留期限和重复结果。不能只依赖前端禁用按钮。外部调用设置连接/读取超时，重试限定次数和退避，仅对安全或有幂等保证的操作重试。

本地事务不能保证数据库与消息、缓存、对象存储的原子一致性；按需求设计 Outbox、补偿或可重试状态，并验证失败恢复。只引入中间件不代表一致性已经成立。

${hash}${hash} 7. SQL、日志与健康检查

禁止 SELECT * 和别名.*，包括 XML、注解、动态 SQL、子查询及 CTE；允许 COUNT(*)。显式列字段并处理重名别名。参数值使用绑定，动态列名和排序必须白名单化。新增字段同步检查投影、映射、DTO 和测试，避免 N+1 和无界批量操作。

日志包含操作、稳定错误码及必要上下文；敏感值脱敏，业务预期失败与系统异常区分级别。上线前检查异常能定位且不泄露细节，日志保留、滚动和采集遵循运维配置。

存活检查反映进程是否正常，不依赖数据库目录或外部服务；就绪检查按对外服务所需依赖设计。数据库短暂不可用不应仅因此触发进程无限重启。当前 ping 仅提供基础检查，不能当作全部依赖已经就绪的证明。

${hash}${hash} 8. 文件与对象存储

文件上传在后端限制大小、类型和数量，不能信任客户端文件名、扩展名或 MIME。对象键由服务端生成，不接受任意本地路径；下载校验归属与权限，直传和预签名地址限定有效期与权限。

存储管理员密钥不得暴露给浏览器。定义上传中、已关联、失败和待清理等必要状态及清理策略，避免数据库记录与对象永久不一致。是否扫描恶意内容、允许哪些预览格式由项目明确；不把不可信主动内容直接当作同源 HTML 执行。

${hash}${hash} 9. 验证与交付

新增功能覆盖领域规则、异常响应、归属校验、并发冲突和失败恢复；HTTP 契约优先用 MockMvc 内存验证。默认单元测试不监听端口、不连接真实数据库或中间件；外部集成测试采用 *IT 命名并配置显式运行流程，不能认为默认 Maven 测试会自动覆盖它们。

在生成项目根目录执行：

```powershell
mvn -f app-backend/pom.xml clean package
```

提交应同时包含必要实现、迁移、接口说明和测试。评审模块依赖、Lombok 引入、SQL 投影、事务、敏感信息和兼容性；可自动化的检查接入 CI，尚未接入的保持人工检查项。不得擅自启动服务或修改共享环境。
